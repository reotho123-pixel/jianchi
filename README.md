# 坚持

英语 · 健身 · 戒撸，三合一打卡应用。简单、快、看得见坚持的成果。

- **纯离线**：做成 PWA，手机「添加到主屏幕」后完全离线可用。
- **数据在本机**：所有记录保存在浏览器 localStorage（key `jianchi-v1`），不上传服务器；换设备用页面内「导出数据 / 导入数据」迁移。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 应用本体（CSS/JS 全内联，无外部依赖） |
| `manifest.json` | PWA 清单，start_url/scope/id 均为 `./` |
| `sw.js` | Service Worker，缓存名 `jianchi-v2` |
| `icons/` | 192 / 512 / maskable 512 / iOS 180 / favicon 32 |
| `fonts/` | 霞鹜文楷（仅 300 字重），**本地打包，不依赖 CDN** |
| `make-icons.ps1` | 图标生成脚本（PowerShell + System.Drawing） |
| `_deploy.ps1` | 一键部署到 GitHub Pages（需先设置 `$env:GH_TOKEN`） |
| `PRD.md` | 产品需求文档 |

## 功能

**今日**（默认页）
- 三个内置习惯：英语（📖 淡绿，目标 30 分钟，可请假）、健身（💪 淡紫，目标 40 分钟，可休息日）、戒撸（🛡️ 淡蓝，戒断型）
- 手账风卡片：渐变底色、虚线描边、微倾斜、右上角 emoji 水印、达标盖圆形印章
- 每张卡有**近 7 天条**，一眼看出这周哪天断了
- 点卡片「打卡」→ 填时长（快捷值 15/30/45/60 或手动输入）→ 完成，两步内搞定
- 也可「不记时长，直接打卡」
- 达标即进度条填满 + 盖「已达标」印章；没达标也能打卡，不影响连续
- 戒撸双按钮：「坚持住了」记一天；「重新开始」当前连续归零，最长记录与累计保留
- **休息日 / 请假**（详见下节）

**休息日与请假**

| | 休息日 | 请假 |
|---|---|---|
| 用于 | 计划内休息（健身不能天天练） | 计划外中断（临时有事） |
| 必填 | 否 | **是**，需写事由（可点常用原因快捷填入） |
| 限额 | 每周最多 3 天 | 每周最多 3 天 |
| 连续天数 | **不中断** | **不中断** |
| 完成率 | 不计入（也不计入分母） | 同左 |
| 视觉 | 灰斜纹 | 琥珀斜纹 |
| 可开启的习惯 | 健身（默认） | 英语（默认） |

- 每周按自然周（周一起）计算，周一自动重置；用满后按钮禁用并提示「已用满，下周一重置」
- 已打卡后也能改主意：卡片上提供「改休息日」「改请假」
- 记录页可补标：分支视图里点日期 → 「休息」/「请假」
- 在「我的 → 编辑习惯」里可为任何完成型习惯单独开启这两个状态

**记录**
- 习惯切换胶囊（全部 / 单习惯），统计与日历随之变化
- **「全部」日历用同心环展示**：完成一个习惯，日期圆圈里就多一道**实心色带**（苹果健身环那种），颜色对应那个习惯；从外到内依次是 英语 / 健身 / 戒撸，后续添加的习惯自动接在后面
- 休息日、请假在日历上是**对应颜色的斜纹环**，破戒是红色环
- 圆形日期格统一灰底，今天有描边、选中加粗描边、补打右下小圆点
- **一键补齐**：日历下方一行小字提示最近 7 天里哪几天没记录，点一下按各自默认时长全部补上（已有记录不动）
- **补卡在各习惯自己的分支里做**：切到单个习惯，点日期后下方出现该习惯的淡绿色卡片，可「改」「删」「补打」「休息」「请假」
- 统计卡（淡绿）：当前连续 / 最长连续 / 累计天数 / 累计时长 / 完成率，并单列休息请假天数

**我的**
- 习惯管理：增、删、改、排序、归档
- 自定义习惯可选类型（完成型 / 戒断型，创建后不可改）、目标、24 个图标、8 种颜色、是否允许休息日/请假
- **新增习惯会自动分配一个还没被使用的颜色**，保证各项颜色不撞车；也可以自己点选任意颜色
- 数据导出 / 导入 JSON，30 天未备份会提醒
- 清空所有数据（二次确认）

**底部导航**：滑动胶囊（切换时白色胶囊平滑滑动，0.28s 缓动）

## 规则要点

- **完成型连续**：今天没打卡不清零（从昨天往前数）
- **休息日 / 请假不中断连续**，也不计入完成率的分母
- **戒断型连续**：未记录的日子不算破戒、不中断，只有「重新开始」才归零
- **补打**：最近 7 天内可补，带标记且标记不可修改
- **达标 ≠ 完成**：打卡即完成，达标只影响进度条与印章

## 部署到 GitHub Pages

**方式一：一键脚本**（需 GitHub token，权限勾选 `repo`）

```powershell
$env:GH_TOKEN = 'ghp_xxxxxxxxxxxx'
powershell -NoProfile -ExecutionPolicy Bypass -File _deploy.ps1
```

脚本会自动建仓库、上传全部文件（含字体）、开启 Pages，最后输出网址。

**方式二：网页手动上传**

1. 登录 GitHub（`reotho123-Pixel`），新建仓库 `jianchi`（Public）。
2. 上传 `index.html`、`manifest.json`、`sw.js`、`.nojekyll`、`icons/`、`fonts/`（保持目录结构）。
3. Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，保存。
4. 一两分钟后访问 `https://reotho123-pixel.github.io/jianchi/`。

## 字体

霞鹜文楷（LXGW WenKai）**已本地打包**在 `fonts/`，不依赖任何 CDN：

- 只保留 300 字重（全篇细体，无粗体），共 97 个 woff2 分片、约 5.2MB
- 浏览器按需加载，界面实际只用 12 个分片
- Service Worker 已把这 12 个分片加入预缓存，**首次离线打开也有正确字体**
- 这样在国内网络下也不会因 CDN 不可用而掉字体

## 设计

- 字体：霞鹜文楷（LXGW WenKai，CDN 加载），全篇细体、无粗体

- 圆形日期格、大圆角卡片、胶囊按钮与导航
